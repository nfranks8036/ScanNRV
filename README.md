# ScanNRV

Want to know what law enforcement in your area is up to? Or, want to know what those sirens you just heard were about? Then this is the guide for you! Below are some resources I've learned throughout the past 1-2 years on how to efficiently and comprehensively scan the New River Valley - Montgomery. This guide will update should new information come to light. If you have any additional information you'd like to see added, contact `cyberedcake` on Discord (Noah in Firewatch).
